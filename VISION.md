# Vision

**Purpose:** private, invite-only social networks for small organizations and families. Each one comes with a team of AI agents that keeps it running and shapes it to what that group wants.

**Who it is for:** small communities (retreat groups like Sacred Feminine, clubs, churches, families) that want their own private space, not a big public platform.

**How it works:**
- Each organization gets its own private network.
- Its agent team keeps it up to date and secure, takes customization requests, and builds a preview copy with sample data to try changes before they go live.
- Customization is open within set bounds. The core data structure, privacy and safety rules stay fixed, so updates keep working.
- Two ways to run it:
  - a hosted service for a small monthly fee, where you deploy and run it for them;
  - open source, where a group sets it up themselves and pays its own AI costs.

**Sacred Feminine Community** becomes the first organization on it, and the proof that it works.

**Guiding principles:**
1. Privacy and safety first, for every organization.
2. Small and invite-only by design.
3. Agents change things only within the bounds, and nothing goes live without the organization's approval.
4. Cheap to run per organization.
5. The open-source and hosted versions are the same software.

**Non-goals:** public sign-up and discovery, ads, selling data, and becoming a large general social network.
